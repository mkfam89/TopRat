Two run paths: the scheduler/scripts path (discover → score → notify → git → archive, no tokens) and the Claude agent path (orchestrates jobpipe + does tailoring, Chrome scrape fallback, Simplify sync, salary search). Resume customization is deterministic for action=template and LLM-written for action=customize.
