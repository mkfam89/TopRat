Dev tools

A hidden page for tests. It is not in the menu, and no link points to it. Type /dev to open it. It is read-only, except the restart button.

Restart the server

Use this button after you edit a .py file. The running process already holds that code, so an edit does nothing until the server starts again.

You do not need this for .html or .css edits. The server reads the page files from disk on every request and sends them with no-store. A normal browser refresh therefore shows your change to cards.html, setup.html, ui.css and the other pages.

What happens: the page tells the server to stop. The server answers, frees its port, starts a replacement on the same port, and exits. This page then waits for a different process to answer, and it loads itself again. The new server runs hidden in the background, as the watchdog starts it. If you started the server from a terminal, that terminal is no longer attached.
