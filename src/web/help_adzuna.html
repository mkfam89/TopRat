Get more accurate salaries with Adzuna

Optional and free. Without Adzuna, the salary estimates come from the posting text and a hand-maintained band table. With Adzuna, a job that lists no pay also gets a market estimate for the role. That figure is narrower and more accurate.

Why to use Adzuna

Every job gets a salary without Adzuna. If the posting gives a pay range, the pipeline reads it directly. If the posting gives no range, the pipeline uses a family band, for example SRE / Cloud / DevOps  $110k–$145k. The app marks those band figures (est.). They are wide on purpose. The salary predictor of Adzuna replaces a wide band with an estimate for the specific role. The numbers you read are then closer to the market.

Setup steps

  1. Create a free Adzuna developer account.
    Go to developer.adzuna.com/signup and register. The account is free. The Adzuna terms permit use for "personal research".
  2. Open your API Access Details and copy the two values.
    Go to developer.adzuna.com/admin/access_details As an alternative, sign in and open Dashboard → API Access Details. Copy two values from this page:
    • the short code under Application ID. This is your app_id.
    • the long code under Application Keys. This is your app_key. If the page lists no key, click Create new key first.
  3. Paste them into Settings.
    Open the Settings tab of the dashboard. Find the Adzuna salary API card. Paste your Application ID and your Application Key. Then click Save Adzuna keys. The app stores both values locally in config/adzuna.json. Git ignores that file, so your key never goes into a commit. You can also write the file by hand. Copy config/adzuna.json.example and edit it.
  4. Nothing needs a restart.
    The next scheduled run uses Adzuna. A click on $ Find or $ Retry does the same. The app probed some jobs before you added the keys. It probes those jobs again automatically, and their estimates improve. A second scrape is not necessary.

Reference

The free tier permits these request limits:

25 / minute 250 / day 1,000 / week 2,500 / month

The pipeline counts your requests locally. It stops before it reaches a limit. If it does reach a limit, the salaries return to the band estimate and the tracker shows a banner. No function stops. The hourly job radar uses no Adzuna quota. Only the daily run, the weekly run, and your own $ Find clicks use it.
