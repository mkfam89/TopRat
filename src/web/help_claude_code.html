Set up AI resume tailoring

Optional. It rewrites each resume for the posting automatically, using the Claude plan you already pay for. No API key, no per-use billing. Without it, the queue just copies your template.

Steps

  1. Install Claude Code. Follow docs.claude.com/en/docs/claude-code. You never have to use it directly.
  2. Log in. In a terminal, run claude login and sign in with your subscription account. Do not paste a Console API key — that is the pay-per-use path.
  3. Test it. Run claude -p "say OK". A short reply means you are set.
  4. Check it in the app. Go to Settings → AI resume tailoring and press Check now. A green line means it is working.
Clear ANTHROPIC_API_KEY if you have one. When that variable is set, your own terminal claude sessions bill at API rates instead of using your plan. Check it with echo %ANTHROPIC_API_KEY%, clear it with setx ANTHROPIC_API_KEY "", then open a new terminal.

If the check fails

Not foundInstall Claude Code, or put its full path in config/claude_cli.json under "binary".
Found, call failedRun claude login again. Or your plan limit is spent — it resets on its own.
Timed outRaise timeout in config/claude_cli.json (default 240 seconds).
