Configure unattended resume tailoring

Optional. The hourly queue then rewrites a resume for each posting, on the Claude plan that you already pay for.

Flat rate. Nothing metered. This app has no API key, and it never bills you for each use. It calls Claude Code on your own machine, and that call uses the limits of your Claude subscription. If you already pay for Pro, there is nothing more to buy.

What it changes

Without Claude CodeA queued job gets a copy of your base resume from resume_template/. The tailoring instructions you typed on the card sit unread until you open Claude yourself.
With Claude CodeThe hourly queue processor rewrites the summary, the bullet order, and the skills line for that posting, and it reads the instructions you typed. The result still passes the same lint gate, so the app rejects a bad rewrite and does not deliver it.
What it costsNothing more than your plan. It uses the same limits as your interactive Claude sessions. For this reason, keep the daily and hourly auto-tailor caps in Settings low.

Steps

  1. Install Claude Code. Follow docs.claude.com/en/docs/claude-code. It is a command-line tool. You do not need to use it directly.
  2. Log in with your plan. Open a terminal and run claude login. Sign in with the Claude account that holds your subscription. Do not paste a Console API key during the login. That key is the pay-per-use path, and this app does not use it.
  3. Make sure that it works. Run claude -p "say OK". A one-word reply means that the login is correct.
  4. Do the check in the app. Return to Settings → Integrations and press Check now under Unattended tailoring. A green line means the queue can tailor on its own from here.
CAUTION: Watch the ANTHROPIC_API_KEY environment variable. If an API key is present, Claude Code uses that key and not your subscription. Every run then moves to pay-per-use billing. This app removes the variable before it calls Claude Code, so the tailoring here always stays on your plan. But if you set the variable for a different tool, Claude bills your own claude sessions in the terminal at API rates. To see the value, run echo %ANTHROPIC_API_KEY% on Windows. To clear it, run setx ANTHROPIC_API_KEY "". Then open a new terminal.

If the check fails

Not foundClaude Code is not installed, or not on your PATH. Install it, or put the full path in config/claude_cli.json as "binary" (copy config/claude_cli.json.example).
Found, call failedThe login usually stopped. Run claude login. The usage limit of your plan can also be spent. That limit resets by itself.
Timed outThe default cap is 240 seconds. If your machine is slow to start the CLI, increase timeout in config/claude_cli.json.

You can run the same check from a terminal in the app folder: python llm_tailor.py --check

Nothing here is required

Search, match scores, salary estimates, phone alerts, the tracker and resume generation all run as plain scripts, with no Claude. If you turn this off, you lose the rewrite only, and not the pipeline.
