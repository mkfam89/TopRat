Get job alerts on your phone with ntfy

Optional and free. It sends new job matches to your phone, so you do not have to check the dashboard. No account, no API key.

Setup steps

  1. Make a topic name. Copy the string below. You paste it in two places.
  2. Install the ntfy app. Android  ·  iOS  ·  or open ntfy.sh/app in a browser. There is no sign-up.
  3. Subscribe to your topic. Tap +, paste the topic, keep the server ntfy.sh, tap Subscribe. Allow notifications when the phone asks.
  4. Paste the topic into Settings. Go to Settings → Phone alerts. Paste the same string, tick Enable phone alerts, click ✓ Save.
  5. Test it. Click Send test alert. Your phone gets it in a second or two. Nothing needs a restart.

Good to know

What arrivesOne message per run listing the new matches, not one per job. You never get the same job twice.
CostFree.
Turn it offUntick Enable phone alerts in Settings. Everything else keeps working.
No alert arrivesCheck the topic matches exactly (it is case-sensitive), that alerts are enabled and saved, and that your phone allows notifications.
