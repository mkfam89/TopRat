Get job alerts on your phone with ntfy

Optional and free. You do not need an account, an app store login, or an API key. You pick a secret topic name. You subscribe your phone to that topic. This app then sends new job matches to it.

What ntfy is

ntfy (say "notify") is a free, open-source service that sends alerts to your devices. It does not use accounts or logins. It uses topics instead. A topic is any text string that you choose. Each message that goes to ntfy.sh/your-topic appears immediately on every device that subscribes to that topic.

Why this app uses ntfy: the hourly job radar runs as a plain script (notify.py). It does not need Claude, and it does not need an open browser. The radar finds new postings above your match threshold. It then sends them to you through ntfy. One HTTP POST from the standard library does all the work. It costs zero tokens and zero money. It also works while the dashboard is closed.

What you receive

The radar sends one message for each run. It does not send one message for each job:

New job match (3)
Senior SRE - Acme - Houston, TX - 88%
Platform Engineer - Globex - Remote - 81%
DevOps Engineer - Initech - Houston, TX - 74%

A tap on the message opens the dashboard. The app records each job that it sent to you in notified.json. As a result, you never receive a second message for the same posting. Each message holds a maximum of 25 jobs.

CAUTION: Pick a topic name that nobody can guess. All topics are public. A person who knows the exact name can read every message sent to it. Do not use jobs or your own name. Use a long random string, for example jobradar-7f3b91c4d2e8. The secret name is the only thing that keeps your alerts private.

Setup steps

  1. Pick a secret topic name.
    Generate a name here. Then copy it. You paste the same string in two places: your phone, and Settings.
  2. Install the ntfy app on your phone.
    Android (Play Store)  ·  iOS (App Store)  ·  or keep ntfy.sh/app open in a browser tab. The app has no sign-up screen. It opens to an empty subscription list.
  3. Subscribe to your topic.
    In the app, tap + (Subscribe to topic). Paste the topic string from step 1. Keep the default server ntfy.sh. Then tap Subscribe. Android and iOS both ask for permission to send notifications. You must accept. On iOS, keep the app installed. iOS uses APNs, so the app does not need to stay open.
  4. Paste the topic into Settings.
    Open Settings → step 4 (Integrations). Paste the same string into ntfy topic. Select Enable phone alerts. Then click ✓ Save & generate. The app stores the topic in your data folder, in config/notify.json. Git ignores this file, so your topic never goes into a commit.
  5. Send a test alert to yourself.
    In Settings, click Send test alert under the ntfy field. Your phone receives the alert in one or two seconds. Nothing needs a restart. The command python notify.py --test does the same thing.

What sends themThe hourly radar sends the alerts. The daily and weekly runs also send them. All three are scripts. They need no Claude and no browser.
Stop the alertsClear Enable phone alerts in Settings. As an alternative, unsubscribe in the app. All other functions continue to work.
Mute a staging copySet "disable_notifications": true in config/instance.json. This stops the alerts from one installation. It does not change your profile.
Your own serverntfy is open source. You can run it on your own server. This app sends to ntfy.sh. To use a different server, edit notify.py.
No alert arrivesMake sure that the topic name matches exactly. The name is case-sensitive. Make sure that the alerts are enabled and saved. Make sure that the phone permits notifications.
