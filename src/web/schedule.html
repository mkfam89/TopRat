⏱ Scheduled tasks

These tasks run by themselves while this dashboard is open. If the app was closed at a scheduled time, the app skips that run. It then shows the run as Missed, with a Run now button. The switch below keeps the app open for you. Scheduled tasks at the top right of each page counts every item that needs attention.

Pause the searches when the board fills up

The searches also run while you do not read the board. One week away therefore makes hundreds of postings with no decision. Set a limit. The searching tasks in Finding jobs below then wait when that many postings need a decision. If the count goes under the limit, those tasks start again by themselves. The app turns nothing off, and this limit never changes the on or off state of a task. Applied and skipped postings do not count, because they are decided. Set the limit to 0 for no limit.

Restart the dashboard by itself if it stops

The tasks below run only while this dashboard runs. If you turn this on, your computer looks at the dashboard every few minutes. If the dashboard is closed, your computer starts it again. This setting covers a sign-in, an accidental close of the window, and a stop of the app. If you turn it off, the tasks run only while this window stays open.
