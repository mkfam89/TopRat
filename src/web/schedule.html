⏱ Scheduled tasks

These tasks run by themselves while this dashboard is open. If the app was closed at a scheduled time, the app skips that run. It then shows the run as Missed, with a Run now button. The switch below is what keeps the app open for you.

Pause the searches when the board fills up

The searches run whether or not you are reading the board, so a week away turns into hundreds of postings you never decided on. Set a limit, and the searching tasks in Finding jobs below hold off once that many postings are waiting on a decision. They start again by themselves as soon as you get back under the limit — nothing is switched off, and this switch never touches the on/off state of a task. Applied and skipped postings do not count; they are already decided. Set it to 0 for no limit.

Restart the dashboard by itself if it stops

The tasks below run only while this dashboard runs. Turn this on, and Windows checks every few minutes whether the dashboard is running. If it is not, Windows starts it again and puts the window straight into your taskbar, minimized — so signing in does not fill your screen with the dashboard. This covers logging in, closing the window by accident, and the app stopping on its own. Turn it off, and the tasks run only while this window stays open.
